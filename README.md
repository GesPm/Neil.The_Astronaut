# Neil The Desktop Astronaut Assistant

**Neil** is a desktop pet/assistant that walks around your bezels and helps you stay focused (or not) in what your doing with it's features. Neil has AI Integration which is also optional, he remembers your chat history, and analyzes local files dropped directly onto his chatbox ( Locally stores API key ). Also you can drag him around and throw him and he will flail his arms and rotate and bounce sometimes.

Download it on itch.io:
[itch.io](https://gekib.itch.io/neil-the-astronaut)




## Neil's Features

-  **Bezel Walking** Snaps to screen edges, walks along monitor bezels, and flails/bounces when dragged and thrown.
-  **AI Conversation (Optional)** Integrated with Gemini Flash for quick, concise, astronaut-themed replies.
-  **Conversation Memory** Retains short-term conversational context across exchanges.
-  **Drag & Drop File Inspection** Drop `.txt`, `.gd`, `.json`, `.py`, or code files onto Neil for instant summaries or custom analysis.
-  **Local API** Stores your Gemini API key locally in `user://neil_settings.cfg` for instant reconnection on startup.
-  **Annoying Mode (On/Off)** Optional toggle where Neil randomly jumps to the top bezel and closes active tabs.



## Controls


- **Drag / Throw:** Click and hold Left Mouse Button, release to throw
- **Menu** *Right* Click on Neil
- **Analyze Files** Drag any text/code file onto Neil's chatbox

## Setup & Installation

1. Download the latest release from the **Releases** tab (or run directly in Godot 4.x).
2. Launch `Neil.exe`.
3. Right-click Neil, select **Set Gemini API Key** 
4. Enter your Gemini API key from [Google AI Studio] (https://aistudio.google.com/). ( Saved locally ) (hackclub ai integration coming soon)
5. Start chatting!
