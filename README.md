# Neil — Desktop Astronaut Pet

**Neil** is a physics-driven, bezel-walking desktop companion built in **Godot 4** and powered by the **Google Gemini API (Optional)**. He lives on the edges of your screen,
remembers your chat history, and analyzes local files dropped directly onto his suit ( Locally stores API key ).

 **Download playable builds on [itch.io](https://gekib.itch.io/neil-the-astronaut)!**


---

## Features

-  **Physics & Bezel Walking:** Snaps to screen edges, walks along monitor bezels, and flails/bounces when dragged and thrown.
-  **Conversational AI (Optional)** Integrated with Gemini Flash for quick, concise, astronaut-themed replies.
-  **Multi-Turn Memory** Retains short-term conversational context across exchanges.
-  **Drag & Drop File Inspection:** Drop `.txt`, `.gd`, `.json`, `.py`, or code files onto Neil for instant summaries or custom analysis.
-  **Local API Key Persistence:** Stores your Gemini API key locally in `user://neil_settings.cfg` for instant reconnection on startup.
-  **Annoying Mode:** Optional toggle where Neil randomly jumps to the top bezel and closes active tabs.



## Controls & Shortcuts


- **Drag / Throw:** Click and hold Left Mouse Button, release to throw
- **Context Menu:** Right Click on Neil
- **Toggle Chat:** Press `F1` or click "Ask Neil" in the Menu
- **File Scanner:** Drag any text/code file onto Neil

## Setup & Installation

1. Download the latest release from the **Releases** tab (or run directly in Godot 4.x).
2. Launch `Neil.exe`.
3. Right-click Neil, select **Set Gemini API Key** 
4. Enter your Gemini API key from [Google AI Studio] (https://aistudio.google.com/). ( Saved locally )
5. Start chatting!
