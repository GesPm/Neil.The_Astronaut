# Neil The Desktop Astronaut Assistant

**Neil** is a desktop pet/assistant that walks around your bezels and helps you stay focused (or not) in what your doing with it's features. Neil has AI Integration which is also optional, he remembers your chat history, and analyzes local files dropped directly onto his chatbox ( Locally stores API key ). Also you can drag him around and throw him and he will flail his arms and rotate and bounce sometimes. The menu is basic but I love the look because I love old retro scientific computer look, fits it very well.

Download it on itch.io:
[itch.io](https://gekib.itch.io/neil-the-astronaut)




## Neil's Features

-  **Bezel Walking** Snaps to screen edges, walks along monitor bezels, and flails/bounces when dragged and thrown.
-  **AI Conversation (Optional)** Integrated with Gemini Flash or Hackclub AI ( Qwen3-32B ) for quick astronaut themed replies.
-  **Conversation Memory** Retains short-term conversational context.
-  **Drag & Drop File Inspection** Drop `.txt`, `.gd`, `.json`, `.py`, or code files onto Neil and he can analyze or summarize the files like ChatGPT or Claude.
-  **Local API** Stores your Gemini API key locally in `user://neil_settings.cfg` for instant reconnection on startup.
-  **Annoying Mode (On/Off)** Optional toggle where Neil randomly jumps to the top bezel and closes active tabs.
-  **Chat-box Features** Right clicking the chat box when asking Neil a question it gives a lot of options



## Controls


- **Drag / Throw:** Click and hold Neil then throw and release the left click and boom now he flails and spins and sometimes bounces.
- **Menu** *Right* Click on Neil and opens a grey menu in top left. ( Very good design I know, it fits space theme like a old scientific computer )
- **Analyze Files** Drag any text/code file onto Neil's chatbox

## Setup & Installation

1. Download the latest release from the Itch.io link (or run directly in Godot 4.x).
2. Launch `Neil.exe`. ( Also if you want you can drag the zip files onto the desktop and have a quick access whenver you want!! Just double click the .exe after        letting Neil "sleep".
3. Right-click Neil, select **Set Hackclub/Gemini API Key** 
4. Enter your Gemini API key from [Google AI Studio] (https://aistudio.google.com/). or
   Enter your Hackclub AI API key from [Hackclub AI APi key] (https://ai.hackclub.com/dashboard). *All saved locally*
6. Then just start chatting!!!
